Доступ к production, изменение issuer, выдача живых устройств и платные покупки не поручались. Публикация проекта и исходной документации в указанном PRIVATE GitHub repository разрешена D014. Публичные GitHub upstream можно читать без учётных данных. GitHub CLI авторизован; origin проекта — acqu1red/vpnhub. Секреты не требуются для локальных tests.

Изменение утверждённого решения добавляется новой строкой с датой и прямым основанием; исходные цитаты и SPEC_ORIGINAL.md не переписываются.
